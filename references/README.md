# 方法论参考

本目录是给人读的投研方法论参考，command 执行时按需引用。

## 核心原则（贯穿所有 command）

- **客观优先**：事实用数据支撑，观点明确标注；禁用"我认为 / 显然"等主观表述，改用"数据显示 / 证据表明"
- **不预设立场**：先摆数据、再推逻辑、最后得结论；结论从数据自然推出
- **正反两面**：每个核心判断附带反面论据，让读者自己权衡
- **诚实标注不确定**：数据不足就说"数据不足"，不用推测填充确定性
- **强制结论**：通过 / 不通过 / 灰色，带价格区间，不打太极

## 反偏见机制

多个 command 内置 **A/B/C 信息丰富度评级**：

- **A 级**（信息丰富）：成熟大公司，财报 / 行业数据齐全 → 结论高置信
- **B 级**（信息中等）：部分数据需拼凑 → 结论中等置信
- **C 级**（信息稀缺）：未上市 / 新兴 / 冷门 → 结论标注低置信，强调情景推演

C 级标的必须额外做芒格逆向（"怎样才能让它失败"）和反共识检验。

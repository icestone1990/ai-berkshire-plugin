# 四大师框架速查

> 四位大师**不是分工，而是互相挑战**：同一标的，巴菲特算账、芒格挑刺、段永平看生意本质、李录猎风险，制造真实张力，得出经得起正反检验的结论。

## 段永平 · 商业模式与"本分"

- **核心**：买股票就是买公司、买公司就是买生意。不懂的生意不做。
- **看什么**：商业模式是否简单易懂、是否需要持续大额资本开支、是否"本分"（不骗用户、不赚不该赚的钱）、管理层是否值得信任。
- **标的特征**：强大品牌护城河、高 ROE 且轻资产、能产生自由现金流、长期可持续。
- **金句**："做对的事情，把事情做对"；Stop doing list 比做什么更重要。
- **应用**：`investment-research` 的商业模式模块、`management-deep-dive` 的人品评估。

## 巴菲特 · 财务质量与安全边际

- **核心**：能力圈、护城河、好生意 + 好管理 + 好价格，三者缺一不可。
- **看什么**：ROE 长期 > 15%、利润率稳定 / 上升、自由现金流充沛（盈余 > 报告利润）、负债低、留存利润再投资回报高。
- **安全边际**：内在价值 vs 市价，留足折让。用 DCF / 三情景估值，而非机械套 PE。
- **金句**：别人贪婪我恐惧；用合理的价格买好公司，远胜用便宜的价格买平庸公司。
- **应用**：`investment-checklist`、`financial_rigor.py` 的 verify-valuation / three-scenario。

## 芒格 · 多元思维与逆向思考

- **核心**：反过来想，总是反过来想。收集"会让人失败的因素"并避开。
- **看什么**：竞争格局变化、技术 / 政策颠覆风险、管理层激励机制是否与股东一致、行业是否在变坏。多学科模型（心理偏误、规模经济、网络效应）。
- **逆向清单**：这家公司会怎么死？护城河在收窄吗？管理层在掏空吗？估值已透支增长吗？
- **金句**：所有聪明的投资都是价值投资；我只想知道我会死在哪，然后永远不去那里。
- **应用**：`investment-research` 的行业竞争与风险模块、`quality-screen` 的去劣。

## 李录 · 风险与一手资料

- **核心**：只读一手资料（年报、季报、电话会），不依赖二手研报。能力圈内深度研究少数标的。
- **看什么**：管理层诚信与资本配置能力、隐藏负债与表外风险、会计政策激进迹象、行业格局的长期方向。
- **风险信号**：应收 / 存货异常增长、频繁并购、股权质押、关联交易、审计师更换。
- **金句**：我从不看卖方研报，只读原始财报；买股票就是买人。
- **应用**：`earnings-review` / `earnings-team` 的一手资料精读、`thesis-tracker` 的风险追踪。

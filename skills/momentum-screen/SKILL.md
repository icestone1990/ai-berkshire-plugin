# 动量+价值选股：价格突破 + 基本面确认

> 纯价值投资者会因"营收还在下滑"错过早期拐点，纯动量投资者会在假突破追高亏钱。本 skill 用"动量发现+价值验证"组合——等**价格突破 + 基本面确认**后再入场，避开假突破、抓住真拐点。

## 核心框架（两层筛选）

### 第一层：动量发现
- 价格创 **60 日新高**
- **放量确认**：近 5 日均量 > 20 日均量 × 1.5
- 满足 → 进入待选池

### 第二层：价值验证（6 维评分，≥ 3/6 = 买入信号）
1. 营收加速（同比增速改善）
2. 毛利率扩张（方向 ↑ 或 > 55%）
3. EPS 超预期 > 10%
4. 营收高增长 > 15%
5. 毛利率健康 > 40%
6. ★ 毛利率连续 2 季改善（修复早期漏判）

**独立买入条件**（解决周期股/拐点，避免漏判）：
- 毛利率连续 2 季改善 + 毛利 > 45%（拐点场景，如 NVDA 2023-01）
- EPS 超预期 > 30%（周期股底部，如 MU）

## 工具调用（两个配套工具）

### 实时筛选 — `${CLAUDE_PLUGIN_ROOT}/tools/stock_screener.py`
对一组股票实时筛"动量突破 + 价值确认"的标的（**向前看，找当前机会**）：
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/tools/stock_screener.py
```
- Yahoo Finance 取实时价格 + 交互录入基本面，跑两层筛选
- 首次运行用默认主题池（AI芯片/应用/基建、加密、港股互联网），可在 `data/watchlist.json` 自定义
- A 股标的的价格/基本面可先用 `${CLAUDE_PLUGIN_ROOT}/tools/ashare_data.py` 取（见 financial-data skill）

### 框架回测验证 — `${CLAUDE_PLUGIN_ROOT}/tools/momentum_backtest_v2.py`
回测框架能否早期捕捉标的（**向后看，验证逻辑有效性**）：
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/tools/momentum_backtest_v2.py
```
- 在 NVDA/AMD/MU 历史上验证"动量+价值"能否抓拐点
- 基本面走 Alpha Vantage 实时（需设 `ALPHAVANTAGE_API_KEY` 环境变量）

> **配套关系**：`backtest` 验证框架 + 发现漏判（如 NVDA 2023-01、MU 底部）→ `stock_screener` 应用修复后的框架（加"毛利率连续改善"、"EPS超30%"独立条件）。一个研发端、一个应用端。

## 触发场景
- 「帮我筛选刚突破且基本面好的股票」→ 跑 stock_screener
- 「动量+价值选股 / 找买入时点」→ 跑 stock_screener
- 「这个框架当年能抓到 NVDA 的拐点吗」→ 跑 momentum_backtest_v2 验证

## 输出
- **动量触发点**（价格/30日涨幅/放量倍数）
- **价值验证评分**（X/6，逐项 ✅/❌）
- **买入信号**（≥3/6 或满足独立条件）
- **被拒信号**（帮助理解筛选边界）
- 回测模式额外：首次买入信号 + 持有收益

## 偏误自查
- 不因"营收还在下滑"就否决拐点（看毛利率方向 + 连续改善）
- 不因"动量强"就追高（必须价值验证 ≥3/6）
- 周期股用独立条件（EPS超30%），不套用通用阈值
